04 — About

Built like a product,
not a prototype.

CreativeFlow is an engineering showcase of an AI creative agency workflow: a typed data model for requirements and briefs, a service layer where mock engines can be swapped for a voice agent and Gemini/Veo production, and a frontend that treats the pipeline as a first-class product surface.

The conversation engine, the brief builder and the production pipeline each sit behind a small interface. Connecting real telephony or real generation changes an implementation — never the application.
